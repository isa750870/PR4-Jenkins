# ПроизводствоПро

Практическая работа № 4
по дисциплине «Методологии разработки программного обеспечения».

Вариант 10.

## Назначение

Демонстрация Jenkins Pipeline на примере страницы системы
автоматизации управления производством.

## Файлы

- index.html — демонстрационная страница.
- test.sh — автоматизированные проверки.
- Jenkinsfile — описание конвейера.
- README.md — описание проекта.

## Этапы конвейера

1. Preparation — проверка рабочей области.
2. Build — создание каталога build и копирование страницы.
3. Test — проверка собранного файла.
4. Package — создание и сохранение архива.

## Результат успешной сборки

Артефакт proizvodstvo-pro-v10.tar.gz, содержащий build/index.html.

Проект демонстрирует сборку, проверку и упаковку.
Развёртывание на сервере приложений не выполняется.
